# Слой доступа к данным

Здесь будут реализации репозиториев для пользователей, площадок, мест,
мероприятий и билетов из `ARCHITECTURE.md`. Они будут выполнять запросы к PostgreSQL.
Интерфейсы репозиториев для сервисов будут определены в `app/domain/`.

В лабораторной №3 health-check проверяет работу процесса и не требует базы данных,
поэтому фиктивный репозиторий и подключение к PostgreSQL не создаются.
