# Event Ticketing API

Серверное приложение (REST API) для продажи билетов на мероприятия. Индивидуальный сквозной проект по дисциплине «Разработка серверных приложений» (вариант 6).

Организатор создаёт площадки и мероприятия, зрители покупают билеты на свободные места. Сервер исключает двойную продажу одного места.

## Стек

- Python 3.11, FastAPI
- PostgreSQL 16
- Alembic (миграции)
- Docker, Docker Compose
